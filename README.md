# SFLA — Single-File Local Applications

SFLA is a collection of local-first browser applications built around a
simple idea: useful software does not always need an application server,
installation process, framework, package manager, or large runtime
dependency chain.

SFLAs are designed to be portable, browser-native, and respectful of
user-owned data.

## Design Principles

SFLA projects generally emphasize:

- Local-first operation
- Browser-native capabilities
- User-owned files and data
- Portability
- Minimal runtime dependencies
- Small software supply chains
- Applications that remain useful without unnecessary infrastructure

Individual applications may use external services when a feature
explicitly requires them.

## What Does SFLA Mean?

**SFLA** stands for **Single-File Local Application**.

It describes an architectural approach in which a useful application
can be delivered as a self-contained browser application and run
locally with little or no supporting infrastructure.

The goal is not simply to put everything into one file. The broader
goal is to keep software understandable, portable, durable, and under
the user's control.
