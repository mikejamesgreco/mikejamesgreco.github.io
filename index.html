What is an SFLA?

Single-File Local Application is the architectural approach used here: a self-contained browser application intended to be easy to run, move, inspect, and preserve. The emphasis is on local-first operation, browser-native capabilities, user-controlled data, and a deliberately small software supply chain. Individual applications may contact external services only when a feature explicitly requires it.
