Local-first browser applications with no installation

SFLA brings together free browser-based applications for CSV editing and data analysis, browser-local AI experiments, password management, JVM monitoring, weather comparison, Roku control, and games. The applications emphasize local-first operation, user-owned files, portability, browser-native capabilities, and a deliberately small runtime dependency chain.

What is a Single-File Local Application?

Single-File Local Application (SFLA) is the architectural approach used here: a self-contained browser application intended to be easy to run, move, inspect, and preserve. The emphasis is on local-first operation, browser-native capabilities, user-controlled data, and a deliberately small software supply chain.

Why local-first browser applications?

A local-first application can perform much of its work directly in the browser instead of requiring an application server for every operation. For tools that work with user-owned files, this can keep the normal workflow close to the user and make the application easier to move, preserve, and understand.

Do SFLA applications upload my files?

Ordinary local-file workflows are designed to remain local unless an application feature explicitly needs to communicate with an external service. Individual SFLAs document those boundaries because some features, such as API calls or online weather data, inherently require network access.

Do I need to install anything?

Most SFLAs are designed to run directly in a modern browser from a hosted page or standalone HTML file. A few applications that interact with local operating-system resources may use a small local bridge, and those applications identify that requirement in their documentation.

Can an SFLA run offline?

Applications whose features depend only on local browser capabilities can generally continue to operate without a remote application backend. Features that intentionally use internet services naturally require connectivity while those features are in use.

Are SFLA applications free?

The applications listed on this site are available to launch without an application subscription. Source and documentation links are provided with each application so visitors can inspect the projects and understand how they work.
